# 不具合修正

エラーや誤動作が修正された変更をまとめています。新しい順に並んでいます。

---

### [Claude Code] Windowsで重要なフォルダを削除できてしまう問題を修正
**バージョン**: v2.1.283 | **日付**: 2026-09-25

Windows の PowerShell ツールで、`rd`・`rmdir`・`del` などのコマンドを使うと、ドライブの最上位やホームフォルダなど、本来は削除を拒否すべきフォルダを削除できてしまう問題が修正されました。

---

### [Claude Code] Windowsで一時フォルダへの書き込みが失敗する問題を修正
**バージョン**: v2.1.281 | **日付**: 2026-09-23

Windows で一時フォルダ（`$TMPDIR`）に書き込むコマンドが「Permission denied（許可なし）」で失敗する問題が修正されました。複数のセッションが同時に更新すると `claude.exe` が消えてしまうことがある問題も直っています。

---

### [Claude Code] VS Code拡張がPython拡張の不具合で起動しない問題を修正
**バージョン**: v2.1.280 | **日付**: 2026-09-22

VS Code の Python 拡張機能が起動処理で止まると、Claude Code がいつまでも起動しない問題が修正されました。60秒待っても応答がない場合は、Python環境なしで起動します。

---

### [Anthropic Python SDK] Python 3.13 で終了時に落ちる問題を修正
**バージョン**: v1.8.0 | **日付**: 2026-09-22

ストリーミング（返答を少しずつ受け取る方式）の接続を開いたままプログラムを終了すると、Python 3.13 でクラッシュする問題が修正されました。

---

### [Anthropic Python SDK] Bedrock 経由のエラーを正しく伝えるように
**バージョン**: v1.7.0 | **日付**: 2026-09-18

Amazon Bedrock（AWS上でClaudeを使うサービス）経由のストリーミングで、途中のエラーがAPIエラーとして正しく報告されるようになりました。

---

### [Claude Code] VS Code拡張が設定ファイルを壊すことがある問題を修正
**バージョン**: v2.1.274 | **日付**: 2026-09-17

VS Code拡張からの設定の書き込みが重なると、`~/.claude/settings.json` が読めない状態になったり、設定が消えたりする問題が修正されました。

---

### [Claude Code] 一度きりの予約実行が2回動くことがある問題を修正
**バージョン**: v2.1.269 | **日付**: 2026-09-11

クラウドで一度だけ実行するよう予約したルーティン（定期・予約実行の作業）が、サーバーの一時的なエラーのあとに2回目も実行されることがある問題が修正されました。

---

### [Claude Code] 長時間のクラウドセッションで保存ファイルが消える問題を修正
**バージョン**: v2.1.268 | **日付**: 2026-09-10

約6時間以上続くクラウドセッションで、保存用フォルダに書いたファイルが知らないうちに失われる問題が修正されました。保存したファイルは最長1日保持されます。

---

### [Anthropic Python SDK] 他人が読める認証ファイルを使わないように
**バージョン**: v1.5.0 | **日付**: 2026-09-10

認証情報を保存したファイルが、同じパソコンの他のユーザーからも読める設定になっている場合、そのファイルを使わずに拒否するようになりました。

---

### [Claude Code] 厳しすぎた禁止ルールの判定を元に戻した
**バージョン**: v2.1.260 / v2.1.273 | **日付**: 2026-09-03 / 2026-09-15

ファイル読み取りの禁止ルールを Bash コマンドにも当てはめる変更（v2.1.259・v2.1.268）により、`npm run build` などの無害なコマンドまで拒否されていたため、この変更が取り消されました。

---

### [Claude Code] 起動後に作った `.claude` フォルダの設定が読まれない問題を修正
**バージョン**: v2.1.257 | **日付**: 2026-09-01

Claude Code の起動後に作成した `.claude/` フォルダ内の設定が、再起動するまで反映されない問題が修正されました。

---

### [Claude Code] VS Code拡張がWindowsで起動しない問題を修正
**バージョン**: v2.1.137 | **日付**: 2026-05-09

VS Code（コード編集ソフト）のClaude拡張が、Windowsで起動しない問題が修正されました。

---

### [Claude Code] VS Code拡張がWindowsで起動しない問題を修正（同梱SDKのパス）
**バージョン**: v2.1.131 | **日付**: 2026-05-06

VS Code拡張がWindowsで起動しない問題が修正されました。原因は、同梱のSDKにビルド時のパスが固定で書き込まれていたことでした。

---

### [Claude Code] Mantle エンドポイントの認証エラーを修正
**バージョン**: v2.1.131 | **日付**: 2026-05-06

Mantle エンドポイントへの接続で、`x-api-key` ヘッダーが送られず認証に失敗する問題が修正されました。

---

### [Anthropic Python SDK] Webhookの設定を調整
**バージョン**: v0.100.0 | **日付**: 2026-05-06

Webhook（外部サービスへイベントを通知する仕組み）の設定が調整されました。

---

### [Anthropic Python SDK] リアルタイム受信中にメッセージ情報が欠ける問題を修正
**バージョン**: v0.98.0 | **日付**: 2026-05-04

ストリーミング（AIの返答をリアルタイムで受け取る方式）中に、メッセージの停止理由などの情報が正しく伝わらない問題が修正されました。

---

### [Anthropic Python SDK] ファイル複数送信時のフォーマットエラーを修正
**バージョン**: v0.98.0 | **日付**: 2026-05-04

ファイルを複数まとめて送信するときのデータ形式に誤りがあったため修正されました。

---

### [Claude Code] OAuthログインが失敗し続ける問題を修正
**バージョン**: v2.1.123 | **日付**: 2026-04-29

特定の設定（`CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1`）を使っているとき、OAuth（外部サービスとの認証連携）が401エラーを繰り返してログインできなくなる問題が修正されました。

---

### [Anthropic Python SDK] API仕様書の誤りと機能欠落を修正
**バージョン**: v0.97.0 | **日付**: 2026-04-23

API（外部からClaudeを使うための仕組み）の仕様定義に複数の誤りがあったことと、一部の機能が消えていた問題がまとめて修正されました。
